# Filtro TIM · MS · Licores & Generador IMD (Tottus)

Aplicación web integral para el procesamiento, filtrado de transferencias (TIM), gestión de sobrantes (MS), control de licores y generación de formatos IMD para operaciones logísticas.

## 🚀 Características Principales

- **Procesamiento de Archivos TIM**: Carga rápida y procesamiento en memoria de archivos Excel de transferencias.
- **Filtro Especializado de Licores y MS**: Separación y cálculo automático de mermas, sobrantes y categorías restringidas.
- **Generador de Formatos IMD**: Creación de informes de despacho y transporte con plantillas formateadas.
- **Historial y Registro de Actividad**: Guardado de transacciones locales con acceso rápido y descargas.
- **Diseño "Torre de Control"**: Interfaz moderna con soporte completo para Tema Oscuro y Tema Claro, estética adaptada a la identidad corporativa de Tottus.
- **100% Client-Side**: No requiere backend ni base de datos externa; todo el procesamiento se realiza en el navegador con SheetJS y ExcelJS.

## 🛠️ Tecnologías Utilizadas

- **HTML5 / Vanilla CSS3 / JavaScript Moderno (ES6+)**
- **SheetJS (xlsx.full.min.js)**: Lectura y manipulación de datos tabulares.
- **ExcelJS**: Generación y formateo estilizado de hojas de cálculo.
- **Tipografías**: Barlow Condensed, Inter e IBM Plex Mono (Google Fonts).

## 💻 Cómo Ejecutar

1. Clona este repositorio o descarga los archivos.
2. Abre `index.html` o `FiltroTIM_IMD_v34_IMD_CORREGIDO.html` en cualquier navegador moderno (Google Chrome, Microsoft Edge, Safari, Mozilla Firefox).
3. ¡Listo! No requiere instalación ni servidores locales.
